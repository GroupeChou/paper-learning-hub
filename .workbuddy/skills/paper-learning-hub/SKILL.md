# Paper Learning Hub

这个技能用于论文研学知识库的每日自动化流程。

**核心定位**：论文搜集 + 学习路线生成 + 精简技术介绍。
**不做任何翻译工作**。

## 什么时候使用

当用户要求你：

- 跑一次论文自动研学日任务
- 为新入库论文生成技术摘要
- 更新今日学习大纲和路线
- 重建知识库站点并同步 GitHub

## 运行原则

1. 先让脚本完成发现、下载、状态准备
2. 再由 WorkBuddy 负责：阅读论文 → 生成精简技术摘要 → 构建学习路线
3. 最后回到脚本完成站点构建和 Git 推送

## 固定流程

### Step 1. 准备任务

在项目根目录运行：

```bash
./run_daily.sh --prepare-workbuddy
```

然后打开：

- `.workbuddy/daily-brief.md`
- `.workbuddy/jobs/<paper_id>/job.md`

### Step 2. 处理论文

对于每篇 `job.md`：

1. 阅读原文 PDF，理解论文核心内容
2. 生成精简技术摘要，写入 `papers/zh/<paper_id>/paper_zh.md`
3. 写入 `.workbuddy/jobs/<paper_id>/result.json`

**输出格式要求**（精简技术摘要模板）：

```markdown
---
title: "论文英文标题"
source: "https://arxiv.org/abs/XXXX.XXXXXvX"
---

# 论文标题

**原文链接**：[arXiv PDF](https://arxiv.org/pdf/XXXX.XXXXXvX) | 点击阅读原论文完整内容

- **作者**：作者列表
- **机构**：机构名称
- **发布日期**：YYYY-MM-DD
- **标签**：`标签1` `标签2` `标签3`

---

## 核心问题

1-2 句话说明论文要解决什么问题。

## 方法概述

- 关键思路 1
- 关键思路 2
- 关键思路 3
（3-5 个要点，不展开细节）

## 核心结果

| 指标 | 基线 | 本文方法 | 提升幅度 |
|------|------|---------|---------|
| 指标1 | XX | XX | +X% |

## 为什么值得关注

1 句话总结这篇论文的贡献或启发。

## 学习路线

- **前置知识**：需要了解的概念/论文
- **相关论文**：同一方向的延伸阅读
- **深入方向**：如果想继续深入，可以关注什么
```

### Step 3. 收尾构建

全部论文处理完成后运行：

```bash
./run_daily.sh --build-only
```

这一步会：

- 同步 WorkBuddy 输出到数据库
- 重建 MkDocs 站点
- 自动执行 Git add / commit / push

## 失败处理与重试机制

### 重试规则（必须遵守）
- **单篇论文最多重试 3 次**
- 每次失败后记录到 `result.json` 的 `retry_count` 字段
- 第 3 次仍然失败时，写入 `result.json` 为 `failed`，**跳过该论文**
- 失败的论文在下次运行时会重新加入队列

### 失败处理流程
1. 首次失败 → `retry_count: 1`，重试
2. 第2次失败 → 增加 `retry_count`，重试
3. 第3次失败 → `result.json` 状态设为 `failed`，记录 `failure_reason`，跳过
4. **不要因为单篇失败阻断其他论文**

### GitHub 推送前提条件
**重要：必须满足以下全部条件才可推送 GitHub**
1. ✅ 所有论文的 `result.json` 都已写入（成功或已标记 failed）
2. ✅ 至少 95% 的论文处理成功
3. ✅ `./run_daily.sh --build-only` 执行成功
4. ✅ Git push 返回成功

**禁止行为**：
- ❌ 部分论文未处理完成就运行 `--build-only`
- ❌ 推送时仍有论文处于"处理中"状态
- ❌ 忽略失败论文不做记录

## 工作风格

- **技术摘要 ≠ 翻译**。用中文精炼论文的技术贡献，不逐句翻译原文
- **精炼而不失真**。保留核心方法 + 关键数据，不主观臆测
- **链接导向**。每篇论文必须提供 arXiv 链接，用户自行深入阅读
- **学习路线导向**。关注论文在知识图谱中的位置，而非内容全覆盖
- 不确定的内容标记 `待确认`，不编造信息
