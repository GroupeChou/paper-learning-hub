# paper-learning-hub · memory/

记忆系统 v3.0 项目级记忆目录。

## 文件说明

| 文件 | 说明 |
|------|------|
| `MEMORY.md` | 项目专属长期知识（产出索引、自动化状态、项目约定） |
| `README.md` | 本文件 |
| `YYYY-MM-DD.md` | 每日工作日志（仅保留最近4份， older → `.archive/`） |
| `.archive/` | 30天前日志归档 |

## 写入规则

- **MEMORY.md**: 项目约定、关键决策、产出索引 → 直接编辑
- **YYYY-MM-DD.md**: 每次实质性工作后追加 → 仅追加，不覆盖
- **.archive/**: 每月清理日日志，移入此目录

## 与 Claw 项目共享

跨项目事实（用户偏好、通用约定）写入 `~/.workbuddy/MEMORY.md`（Layer 2），不在此重复。
