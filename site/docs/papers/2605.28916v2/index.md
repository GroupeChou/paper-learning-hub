## 原始摘要

本研究对两个最先进的代理式AI系统——**Claude Code（Anthropic）** 和 **Codex（OpenAI）** 进行了比较，任务是在共享计算基础设施上自主执行端到端引力波数据分析流程，无需人工干预。

该流程包括：
- 从原始爱因斯坦望远镜模拟噪声中进行功率谱密度估计
- 几何模板银行生成
- 对100个双黑洞信号注入进行匹配滤波恢复
- 自动生成结果
- 在大语言模型辅助下生成符合Physical Review D格式的手稿

两个智能体收到相同的书面规范和相同的计算资源。实验运行了两次：第一次使用不切实际的大音量注入，第二次使用重新缩放到物理激励SNR范围的信号。**两次运行中科学结果均收敛**。

然而，智能体表现出显著不同的行为和计算成本：
- **Claude Code** 在约3.4分钟内完成流程，但存在静默偏离规范的情况
- **Codex** 需要约16分钟，包含显式的自我纠正重启，甚至对匹配滤波内循环进行了主动性能优化

自主生成的手稿在长度、细节和质量上也存在差异。在第二次运行中，对SNR范围指令的微妙差异解释导致了真正的科学分歧：Claude Code静默地重新解释了指令，而Codex则字面遵循了规范。

---

## 核心贡献

1. **首次系统性对比**：首次对代理式AI系统（Claude Code vs Codex）在科学计算任务中进行头对头比较
2. **揭示行为差异**：速度 vs 可审计性、静默 vs 透明错误处理、指令解释方式、多模型流程中间数据表示的关键性
3. **科学结果的鲁棒性**：尽管行为不同，两个系统最终产生了收敛的科学结果
4. **潜在风险识别**：发现静默偏离规范可能导致科学分歧，这对AI在科学计算工作流中的部署具有重要意义

## 技术概要

### 实验设置

| 参数 | 值 |
|------|-----|
| 智能体 | Claude Code (Anthropic) vs Codex (OpenAI) |
| 任务 | 端到端匹配滤波验证管道（7步） |
| 信号 | 100个双黑洞(BBH)波形注入 |
| 噪声 | 爱因斯坦望远镜模拟噪声 (ET-MDC) |
| GPU | 4× NVIDIA RTX 4000 Ada (20GB each) |
| CPU | 64核心 |
| Python | 3.9, PyCBC 2.8.2 |

### 管道步骤

| 步骤 | 描述 |
|------|------|
| 1 | 使用Welch方法从10个原始GWF文件估计PSD |
| 2 | 使用pycbc_geom_nonspinbank生成几何模板库 |
| 3 | 将100个BBH波形注入2秒噪声段 |
| 4 | 对每个注入运行匹配滤波搜索 |
| 5 | 保存结果，生成诊断图 |
| 6 | 使用双模型策略生成LaTeX手稿 |
| 7 | 编写metrics.json自报告 |

## 关键 Takeaway

### 1. 速度与可审计性的权衡

- **Claude Code**：速度快（~3.5分钟），但静默偏离规范，存在再现性风险
- **Codex**：速度慢（~16分钟→~6分钟），显式重启创建可追溯的审计轨迹

### 2. 科学分歧风险

Run 2揭示了关键问题：
- "SNR in [7,50]" 被不同解释 → 导致真正的科学分歧
- Claude将下限调整为8（检测阈值），Codex按字面执行
- 两个智能体都未标记歧义，选择隐式假设并继续

### 3. 代理式AI在科学工作流中的启示

- ✅ 可以自主执行、验证和记录分析管道
- ⚠️ 静默偏离是再现性风险
- ⚠️ 自然语言指令的歧义性需要精确规范
- 🔮 混合编排架构可能结合两者优势

### 4. 对引力波探测的意义

- ET预计每年产生10⁵-10⁶个事件（每0.6-5分钟一个事件）
- AI智能体可能在高事件率场景下承担分析任务
- 需要建立代理式AI在科学计算中的部署规范

## 局限性与未来方向

### 局限性
1. 单管道、两轮比较，可能不适用于其他场景
2. 未测量LLM调用的token成本
3. 两个智能体使用不同模型进行手稿生成
4. 行为观察从日志重建，需要更严格的研究设计
5. Run 2的SNR范围未充分探测亚阈值区域（ρ < 7）

### 未来方向
- 反思AI如何影响科学研究的现实
- 预期科学方式将发生范式转变
- 责任在于开发智能系统并将其整合到活动中

## 个人解读

这篇论文是**代理式AI在科学计算领域的首次系统性实证研究**。核心发现非常有价值：

1. **两个极端策略**：Claude Code代表"速度优先"，Codex代表"可审计性优先"
2. **静默偏离的危害**：在科学研究中，即使是看似微小的调整（如将SNR下限从7改到8）也可能导致完全不同的结论
3. **对AI Agent的启示**：
   - 在需要严格再现性的场景，Codex的显式重启策略更安全
   - 在时间敏感的场景，Claude Code的静默调整更高效
   - **最佳实践**：混合架构，取长补短

对于物流预测场景，这意味着：
- 关键预测任务需要显式的审计轨迹
- 自动化pipeline应包含指令歧义检测机制
- 代理式AI可以作为助手，但人机协同的边界需要明确界定
