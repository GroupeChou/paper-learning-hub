## 摘要

视觉语言模型在复杂问题上展现出强大的推理能力，但许多现实世界问题需要借助外部工具，而内部推理无法独立解决。智能体推理因此交织了两种具有结构性不对称的行为：**思考**（Thinking，自我包含的默认行为）和**工具使用**（Tool use / Acting，高方差的辅助行为）。作者将这种不对称称为**思考-行动鸿沟**（Thinking-Acting Gap）。在标准 RL 方法（如 GRPO）下，这一鸿沟在训练过程中表现为两个可诊断的症状：工具使用仅在约 30% 的 rollout 中被尝试；而当工具被尝试时，同一组内使用工具的 rollout 在约 40% 的问题上全部失败，抑制了工具调用处最需要的学习信号。该文提出 **AXPO**（Agent eXplorative Policy Optimization，智能体探索式策略优化）：对于每个"全部错误的工具使用子组"，AXPO 固定思考前缀（thinking prefix）并重新采样工具调用及其延续，配合基于不确定性的前缀选择。在九个多模态基准测试和三个规模的 Qwen3-VL-Thinking 模型上，SFT + AXPO 在平均 Pass@1 和 Pass@4 上超过 SFT + GRPO（8B 模型平均 +1.8pp），且 8B 模型在 Pass@4 上以 4 倍更少的参数超越 32B Base。

## 1. 引言

### 中文翻译

大语言模型（LLMs）和视觉语言模型（VLMs）在扩展推理能力方面取得了显著进展，能够生成思维链（chain-of-thought），在数学和科学推理基准上匹敌更大的模型。这些推理模型将测试时计算投入内部搜索和反思以得出准确答案。

然而，许多现实世界问题超出了纯内部推理的能力范围：检索最新知识、执行复杂数值计算、理解细粒度视觉细节——所有这些都需要访问外部资源。工具——如网络搜索、代码解释器和图像操作工具——可以填补这一空白，实现作者所称的**多模态智能体推理**（Multimodal Agentic Reasoning）：模型自主决定何时继续思考、何时通过工具行动。

智能体推理在其两个组成行为之间存在一种更深层的不对称性：**思考**和**工具使用**（行动）。思考是默认模式，自包含在模型的 token 空间内：每个 token 都在模型控制之下，错误可以通过探索不同的思维链来纠正。工具使用则相反，是一种辅助行为，既强大又脆弱：一个简短的 token 序列触发外部响应，而模型无法预测或控制该响应；调用中的微小变化可能导致截然不同的结果（例如，缩进错误的 Python 代码）。推理模型经过大量后训练来改善思考，但在工具使用方面训练不足。作者将这种安全默认行为与高方差辅助行为之间的不对称称为**思考-行动鸿沟**。

由于这一鸿沟，即使是最新推理 VLM 也难以可靠地 eliciting 智能体推理。仅靠提示（prompting）往往不足以保证在需要时做出恰当的工具调用。这需要后训练流程，如监督微调（SFT）和强化学习（RL）。

SFT 能可靠地教会工具使用的机制，但难以教会模型在教师示范未覆盖的情况下更好地利用工具。最终的智能体继承了教师的失败模式，通常性能难以超越教师。因此，模型需要超越模仿的训练信号，这促使在 SFT 之后利用可验证结果奖励进行 RL。

然而，GRPO 等 RL 方法在使模型精通行动方面是次优的，因为两种模式会抑制工具调用的学习信号。首先，与纯思考相比，工具使用仍然是 rollout 中的少数行为。其次，当尝试工具使用时，整个 rollout 组同时失败的概率远高于纯思考。在 GRPO 下，这种不对称削弱了两种情境中的工具调用学习信号。

作者的核心洞察是：在工具调用处重新采样可以让模型探索多样化的智能体推理路径——锚定思考前缀（thinking prefix），重新采样工具调用及其延续。当工具使用轨迹失败时，思考前缀可能完全是合理的。从头重新生成完整轨迹浪费了本不是瓶颈的前缀上的预算，而工具调用重采样则将探索精准聚焦于思考-行动鸿沟的表现之处。

### 术语解释

| 术语 | 英文 | 解释 |
|------|------|------|
| 思考-行动鸿沟 | Thinking-Acting Gap | 模型在思考（默认安全模式）和工具使用（高方差辅助模式）之间存在结构性不对称 |
| 工具调用重采样 | Tool-call resampling | 固定思考前缀，重新采样工具调用及其后续延续的操作 |
| 智能体推理 | Agentic Reasoning | 模型自主决定何时思考、何时通过工具行动 |
| GRPO | Group Relative Policy Optimization | 一种基于组内相对优势计算的强化学习方法 |
| AXPO | Agent eXplorative Policy Optimization | 本文提出的通过工具调用重采样缩小思考-行动鸿沟的 RL 算法 |
| 全部错误的工具使用子组 | All-wrong tool-using subgroup | 同一问题中所有使用工具的 rollout 都失败的情况 |
| 组归一化优势 | Group-normalized advantage | 在同一问题的多个 rollout 组内计算相对优势 |

### 关键 takeaway

- 首次系统识别了智能体推理中"思考-行动鸿沟"这一结构性不对称问题
- 提出了 AXPO 算法，通过工具调用重采样（而非简单增加 rollout 数量）来高效探索工具使用
- 在九个多模态基准上验证，8B 模型以 4x 更少参数超越 32B Base

## 2. 智能体推理中的 RL 分析

### 中文翻译

**2.1 预备知识**

**智能体推理**：作者研究 VLM 在给定输入（文本问题+视觉图像）和指令提示时的智能体推理过程，交织思考与工具使用。在每个轮次，模型输出思考段（`<think>...</think>`）和动作（格式化为 JSON 的工具调用，在 `<tool_call>...</tool_call>` 中），然后接收观察结果。工具集包括三种标准工具：Python 解释器、网络搜索和图像放大工具。

**GRPO 的 RL 训练**：标准智能体后训练流程包括 SFT（监督微调）+ RL（强化学习）。给定输入 x，策略 pi_theta 生成 N 个 rollout 的组，每个接收基于答案正确性的二值结果奖励。GRPO 计算组归一化优势值，均匀分配给每个 token，用于通过 PPO-clip 代理目标更新策略。

**2.2 诊断思考-行动鸿沟**

作者通过 RL 训练期间收集的三个诊断测量来具体说明思考-行动鸿沟：

**症状一：工具使用尝试不足。** 与常规智能体 RL 不同，智能体推理中工具使用是可选的——模型可以产生 `<tool_call>` 标签或直接跳到 `<answer>`。在 RL 过程中，包含至少一个工具调用的 rollout 比例约为 20-35%，远低于纯思考的多数。

**症状二：工具使用子组倾向于全部错误。** 当工具被尝试时，工具使用子组全部错误的概率约为 40%（同类纯思考子组约为 25%）。在组归一化优势下，工具调用 token 在两种情境中都收到非正优势：混合组中它们落后于纯思考的成功信号，全错组中优势归零。

**症状三：工具调用在固定思考下支持有意义的重新采样。** 通过固定思考前缀并重新采样 16 次工具调用，获得的工具调用覆盖约 2.9-3.4 个不同的语义聚类，确认工具调用是一个真正的分歧点。

### 图表/公式说明

**Figure 3**：三个子图展示思考-行动鸿沟的实证分析。
- (a) 工具使用的尝试比例在 RL 训练过程中仅 20-35%
- (b) 工具使用子组的全部错误率约 40%，远高于纯思考子组的 25%
- (c) 固定前缀下重新采样的工具调用展现出 2.9-3.4 个语义聚类的多样性

### 关键 takeaway

- GRPO 对工具调用的训练不足是系统性的，不是偶然现象
- 思考-行动鸿沟的三个症状可测量、可诊断
- 工具调用是高效探索的潜在靶点：固定前缀重采样能产生多样化的工具调用

## 3. AXPO：智能体探索式策略优化

### 中文翻译

**3.1 工具调用重采样**

在智能体推理中，策略必须同时学习思考和工具使用，而后者在 GRPO 下训练不足。作者不采用简单增加 rollout 数量 N 来均匀生成工具使用成功样本，而是承诺一个预示将使用工具的思考前缀，将随机性集中在延续部分。

具体来说，设 tau_src 是来自 GRPO 组的一个工具使用 rollout（称为源 rollout），t_src_1 是其包含开头 `<tool_call>` 标签的前缀。工具调用重采样从 t_src_1 绘制 K 个延续，执行其中的工具调用，并将每个重采样轨迹向前展开直到 `<answer>` 标签或轮次限制。每个重采样轨迹与 tau_src 共享固定的思考前缀，在工具调用处分叉。

**理论动机**：工具调用重采样的效率优势体现在：在 GRPO 下，覆盖工具调用的 rollout 率受限于工具使用率 q = Pr[工具使用 | x]，而非 N。每增加一个 rollout，只有 q 的概率落到工具调用上。而重采样从 `<tool_call>` 边界开始，每个重采样延续必然是工具使用的，因此全部重采样预算都聚焦于目标信号。

**命题1（工具调用重采样在恢复工具使用成功方面占优原始采样）**：设 t_src_1 是跨越了工具调用边界的思考前缀，则重采样的 K 次延续包含至少一个正确工具使用 rollout 的概率大于等于原始采样。

**3.2 重采样候选选择**

**触发条件与预算分配**：AXPO 仅对工具使用子组非空且全部错误的组进行重采样——这些正是 GRPO 下工具调用 token 获得非正优势的组。AXPO 对额外预算设置上限（r < 1 的比例），按广度优先分配。

**基于不确定性的前缀排序**：AXPO 通过源 rollout 中工具调用 token 的平均策略概率（可计算的不确定性代理）对候选排序，优先重采样最低置信度的前缀。

**3.3 优势计算**

AXPO 将优势流分解为两部分：

1. **重采样延续的优势**：每个选定前缀的 K 个重采样延续构成独立优势组，计算组内 GRPO 优势，仅应用于延续 token。
2. **源前缀的恢复奖励**：如果重采样恢复了至少一个正确延续，源前缀获得二值恢复奖励（recovery reward）。该恢复奖励替换源 rollout 的原始奖励，产生前缀优势。

最终损失函数为两者之和。

### 术语解释

| 术语 | 英文 | 解释 |
|------|------|------|
| 工具调用重采样 | Tool-call resampling | 固定思考前缀，重新采样工具调用及其后续内容 |
| 源 rollout | Source rollout | 触发重采样的原始失败 rollout |
| 恢复奖励 | Recovery reward | 重采样恢复至少一个正确延续时给予源前缀的二值奖励 |
| 思考前缀 | Thinking prefix | 工具调用之前的思考段 |
| 策略概率 | Policy probability | 模型在特定 token 位置的概率输出 |

### 图表/公式说明

**公式1**：工具调用重采样 vs 原始采样在恢复工具使用成功方面的概率比较。关键机制是重采样使 q 趋近于 1（每个延续都必然使用工具），消除了浪费因子。

**公式2-5**：AXPO 的优势计算和最终损失函数。公式2计算重采样延续的组内优势；公式3定义恢复奖励；公式4计算前缀优势；公式5为总损失。

### 关键 takeaway

- AXPO 的核心创新是将探索预算精准聚焦于工具调用分歧点
- 理论证明工具调用重采样在固定预算下严格优于原始采样
- 恢复奖励机制避免了共享前缀上的梯度冲突

## 4. 实验

### 中文翻译

**4.1 实验设置**
- **基础模型**：Qwen3-VL-Thinking 的 2B/4B/8B/32B 四个规模
- **工具集**：Python 解释器、Tavily 网络搜索、图像放大工具
- **训练数据**：SFT 使用 64K 正确轨迹（约 25% 含工具调用）；RL 使用 16K 过滤子集 + 22K 困难问题
- **基准测试**：9 个多模态基准，分为 Reasoning（MathVision、DynaMath、Math-VR）、Perception（V*、VisualProbe、HR-Bench）、Search（HR-MMSearch、MM-Search）
- **评估指标**：Pass@1 和 Pass@4
- **基线**：Base（仅提示）、SFT（无 RL）、GRPO（无 SFT）、SFT+GRPO

**4.2 主要结果**

| 方法 | Reasoning | Perception | Search | Pass@1 | Pass@4 |
|------|:---:|:---:|:---:|:---:|:---:|
| 8B Base | 59.1 | 54.0 | 53.3 | 55.5 | 67.0 |
| 8B SFT | 63.9 | 57.4 | 58.5 | 60.0 | 71.0 |
| 8B SFT+GRPO | 65.7 | 59.6 | 60.0 | 61.8 | 73.3 |
| **8B SFT+AXPO** | **66.8** | **61.5** | **61.7** | **63.3** | **74.9** |

AXPO 在全部 9 个基准上均取得最佳或次佳结果。在 Pass@4 上 8B AXPO 以 4x 更少参数超越 32B Base（74.9% vs 69.6%）。

**4.3 消融研究**
- 重采样 vs 增加 rollout：+25% 额外重采样预算的 AXPO 获得 +1.1pp 提升，而 +100% 额外采样预算的 GRPO 仅获得 +0.9pp
- 不确定性排名：用随机排序替换不确定性排序，性能下降 3-7%
- 重采样位置：在工具调用处重采样比在思考前缀处更有效

### 术语解释

| 术语 | 英文 | 解释 |
|------|------|------|
| Pass@1 / Pass@4 | Pass@1 / Pass@4 | 1 次 / 4 次尝试中至少一次正确的概率 |
| 消融研究 | Ablation study | 移除或替换组件以验证其贡献的实验 |
| pp | percentage points | 百分点 |

### 关键 takeaway

- AXPO 在所有九个基准和所有模型规模上一致优于 GRPO
- 8B AXPO 以 1/4 参数超越 32B Base，验证了"更聪明地探索"比"更多计算"更有效
- 消融实验确认增益来自工具调用重采样，而非额外计算量

## 5. 结论

### 中文翻译

该文首次识别并命名了智能体推理中的思考-行动鸿沟（Thinking-Acting Gap），这是一个模型在思考（安全默认）与工具使用（高方差辅助）之间的结构性不对称。该鸿沟在基于组的智能体 RL 中表现为两个症状：工具使用仅在约 30% 的 rollout 中被尝试，且工具使用子组在约 40% 的问题上全部错误，导致工具调用 token 上非正优势。

作者提出 AXPO（Agent eXplorative Policy Optimization），一种通过工具调用重采样来缩小鸿沟的 RL 算法。对每个全部错误的工具使用子组，AXPO 固定不确定思考前缀并重新采样工具调用及其延续。在九个多模态基准和 Qwen3-VL-Thinking 的 2B/4B/8B 规模上，SFT + AXPO 一致优于 SFT + GRPO，8B 模型在 Pass@4 上以 4x 更少参数超越 32B Base。

### 关键 takeaway

- 思考-行动鸿沟是智能体推理中一个普遍存在但此前未被系统认识的问题
- AXPO 通过结构化的探索策略而非简单增加计算量来解决该问题
- 方法的有效性在多个规模上得到验证，展现了良好的可扩展性
